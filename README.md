# 🎨 QR Code Studio

A modern, client-side, high-resolution QR Code generator built with **Vue 3 (Composition API)** and **Tailwind CSS**. Customize dots, corners, gradients, and embed logos with real-time preview and export in PNG/SVG formats.

## ✨ Features

- **Real-Time Interactive Preview**: Instant rendering with zero lag powered by `qr-code-styling`.
- **Advanced Dot Patterns**: Square, Dots, Rounded, Extra Rounded, and Classy body patterns.
- **Linear & Radial Gradients**: Multi-stop gradient fills with angle/rotation controls for body patterns.
- **Custom Corner Framing**: Independent customization for outer corner square shape/color and inner center dots.
- **Logo Integration**: Upload custom branding logos with real-time proportional scaling and one-click removal.
- **High-Resolution Multi-Scale Export**:
  - `500 × 500 px` for web & social media
  - `1000 × 1000 px` for standard print & flyers
  - `2000 × 2000 px` Ultra HD for large posters and billboards
  - Vector `SVG` export for infinite scalability
- **One-Click Copy to Clipboard**: Copies image binary directly to clipboard with visual feedback.
- **Responsive & Dark Mode Ready**: Desktop grid layout with sticky preview and system-aware/manual dark mode toggling.
- **Zero Backend Required**: Fully client-side processing; user data never leaves the browser.
